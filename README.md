# redshift-estimation-knn

Photometric redshift estimation using k-nearest neighbours (kNN) on galaxy data from the ATLAS/Deep Fields catalogue.

## Overview

This project estimates galaxy redshifts from photometric features using a k-nearest neighbours approach. It focuses on field-based evaluation between the CDFS and ELAIS-S1 regions, following the train/test split logic used in the original Redshift-kNN workflow.

## Data preparation

The data preparation workflow lives in `source_code/data_prepration/data_extraction.py`.

This script:

- reads the raw FITS catalogue from `data/ATLAS_complete_DR2.fits`
- converts the table to a pandas DataFrame
- saves a combined CSV export to `data/ALTAS.csv`
- strips whitespace from the `field` column
- splits the dataset into:
  - `data/CDFS.csv`
  - `data/ELAIS-S1.csv`

The script also prints the dataset sizes and field distribution for quick validation.

## kNN Models

The kNN implementations are located in `source_code/knn/`.

### knn_fn.py

Implements k-nearest neighbours regression with **Euclidean distance**. Key features:

- Uses optical and infrared flux/magnitude features
- Employs `StandardScaler` normalization
- Grid search over k ∈ [2, 100] to optimize for outlier rate (η₀.₁₅)
- 10-fold cross-validation for robust evaluation
- Custom scoring metric: fraction of predictions with |Δz| > 0.15(1+z)
- Returns best model, predictions, and detailed performance metrics

Usage:
```python
from source_code.knn.knn_fn import knn_eu

best_model, y_pred, metrics = knn_eu(train_df, test_df)
```

### Regression.ipynb

Jupyter notebook for end-to-end kNN regression experiments:

- Loads processed CSV data (CDFS or ELAIS-S1 subsets)
- Supports two training data modes:
  - **Field-based split**: Train on one field (ELAIS-S1 or CDFS) and test on the other
  - **Random selection**: Randomly sample training data from the full dataset
- Applies feature selection and preprocessing
- Trains and validates the kNN model
- Generates performance plots and residual analysis
- Compares results across different train/test strategies

## Notes

- The raw FITS catalogue is stored under `data/`.
- The prepared CSV files are generated by the data extraction script and are used for the field-split experiments.
- The project includes a reference implementation under `Redshift-kNN-2021/` for comparison and validation.
- Feature set: optical (MAG_APER_4_G/R/I/Z) and infrared (flux_ap2_36/45/58/80) magnitudes/fluxes.
- Target variable: photometric redshift (z).
- Performance metric: outlier rate η₀.₁₅ (fraction of |Δz| > 0.15(1+z)) and standard regression metrics (RMSE, MAE, R²).
