# redshift-estimation-knn

Photometric redshift estimation using k-nearest neighbours (kNN) on galaxy data from the ATLAS/Deep Fields catalogue.

## Overview

This project estimates galaxy redshifts from photometric features using a k-nearest neighbours approach. It focuses on field-based evaluation between the CDFS and ELAIS-S1 regions, following the train/test split logic used in the original Redshift-kNN workflow.

## Data preparation

The data preparation workflow lives in `src/data_prepration/data_extraction.py`.

This script:

- reads the raw FITS catalogue from `data/ATLAS_complete_DR2.fits`
- converts the table to a pandas DataFrame
- saves a combined CSV export to `data/ALTAS.csv`
- strips whitespace from the `field` column
- splits the dataset into:
  - `data/CDFS.csv`
  - `data/ELAIS-S1.csv`

The script also prints the dataset sizes and field distribution for quick validation.

## Data directory

The project data directory contains the catalogue and processed data products:

- `data/ATLAS_complete_DR2.fits` — raw FITS catalogue
- `data/ALTAS.csv` — full processed dataset exported from the FITS file
- `data/CDFS.csv` — CDFS subset
- `data/ELAIS-S1.csv` — ELAIS-S1 subset
